# 版本全部釘死，包含間接依賴。
#
# 為什麼要連間接依賴一起釘：這個 repo 一 push，Render 就重新 build，而 build
# 時 pip 抓的是「當下的最新版」。沒有釘版本的話，同樣一份程式碼今天和下個月
# build 出來的是不同的東西——網站可能在你完全沒動程式的情況下壞掉，而且無法
# 回到昨天那個能跑的組合。實際會咬人的多半不是 Flask 本身，是 grpcio、
# protobuf 這些沒人直接寫進清單的間接依賴。
#
# 更新方式（要加套件或升版時跑一次，用的是 Dockerfile 同一個 base image）：
#
#   docker run --rm -v "$PWD/requirements.txt:/req.txt:ro" python:3.11-slim \
#     sh -c "pip install -q -r /req.txt && pip freeze"
#
# 把輸出貼回下面兩個區塊即可。直接依賴那區手動維護，順序照功能分組。
